# CLAUDE.md

Guidance for coding agents working in this repository.

## README screenshot

`docs/screenshot.png` at the top of the README is generated by `scripts/screenshot.sh` (`mise run screenshot`) from example payloads piped into the binary. It does not update itself.

When a change alters anything visible in that image, remind the user that the screenshot should be regenerated, and say so in your final summary rather than leaving it implied. This applies to changes in:

- what `renderOutput` in `main.go`, `renderNarrow` in `narrow.go` or `renderTask` in `subagents.go` prints for the segments the examples show: text, order, separators, colors, truncation, the context bar
- the example payloads or git setup in `scripts/screenshot.sh`
- the theme, sizes or window style in `scripts/ansi2svg.jq`

A change to a segment that none of the examples show (the spend limit, for instance) leaves the image as it is and needs no reminder.

The script needs `jq`, `rsvg-convert` and `oxipng` or `optipng`. Look at the regenerated image before it is committed: an unexpected difference means the output changed somewhere it was not meant to.
